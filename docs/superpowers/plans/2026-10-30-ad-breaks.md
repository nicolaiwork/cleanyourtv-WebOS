# Ad breaks in Live TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a channel's logo disappears for an ad break, the TV dims and mutes the picture (with the channel banner) or switches to one partner channel, and comes back when the logo returns.

**Architecture:** The iptv-curator (Python, LXC 165) watches the channel the TV is on with ffmpeg, learns its logo, and runs a break rule; it answers `GET /breaks/<stream id>.json`, which also keeps the watch alive (a lease). The CleanYourTV service (Node 8-compatible) passes that through as `/api/breaks/now`; the Live TV page polls it every second and dims or switches.

**Tech Stack:** Curator: Python 3.13, FastAPI, numpy (new), Pillow, ffmpeg (subprocess), pytest. Fork: Node.js 8.12-compatible service modules, ES5 page code (Chromium 68), `tools/test` + `sh tools/check.sh`.

**Spec:** `docs/superpowers/specs/2026-10-30-ad-breaks-design.md` (read it first). Samples: `~/Projects/iptv-ad-samples/` (`README.md` has the labels).

Two repositories: **curator** = `~/Projects/iptv-curator` (branch `ad-breaks` from `main`), **fork** = `~/Projects/cleanyourtv-webos-fork` (branch `ad-breaks`, exists). Paths below are relative to the repository named in the task.

## Global Constraints

- Curator: read its `CLAUDE.md`. Never request `get.php`; never probe streams in loops; credentials only via `Settings`, everything logged goes through `config.mask()`. Tests must not need ffmpeg or the network.
- At most **one** provider connection from the curator's watcher at any time (the TV uses one; the account has 3, shared with a friend; relaxed: the watcher may take the last one).
- Break rule values (spec): gone when score `< 0.3`, present when score `>= 0.6`; break starts after the logo has been gone **15 s**; ends after present **2 s**; single-sample spikes never end a break.
- Lease **30 s**; the watcher closes within 30 s of the last poll. Reconnect at most once per **60 s**; give up after **3** failed starts until another stream id is asked for.
- Fork service code: Node 8.12 rules (`AGENTS.md` rule 3: no `??`, `?.`, global `URL` (use `netcompat`), no child `timeout`). Page code: ES5; only `opacity`/`transform` animate; no flex `gap`.
- Fork texts go through `t()`; every new text gets a Danish translation in the fork's `add.da` block at the end of `app/src/js/clock.js` (`tools/test/pages.test.js` fails otherwise). Exact Danish copy: `Ad breaks` → `Reklamer`, `Dim` → `Dæmp`, `Partner channel` → `Partnerkanal`, `Use this channel as partner` → `Brug denne kanal som partner`, `Ads` → `Reklamer`, `Watch the ads` → `Se reklamerne`, `Ads on` → `Reklamer på`, `continues · switching back by itself` → `fortsætter · skifter tilbage selv`.
- Feature off by default. The TV never talks to the curator directly; nothing with credentials crosses TV↔curator.
- Never touch the TV, the LXC or the homelab without Nicolai's yes at the time (Task 9, Task 10); name the undo.

## Review Focus

- Zapping through channels (Up/Down held) must not open a provider connection per channel: a stream id must be asked for **5 s** in a row before its watcher starts (Task 4 test `test_zapping_does_not_start_watchers`).
- Curator unreachable, slow or restarted while dimmed: the TV must undim after 3 failed polls and never stay dark (Task 7 test `fails undim`, Task 6 test `curator down`).
- Viewer changes channel, presses Back, or leaves Live TV during a break: picture and sound back at once, no automatic return from the partner (Task 7 tests `reset`, Task 8 step on `play()`/`o.exit`).
- A stream that stalls (no frames for 20 s) while in a break must report no break (Task 4 test `test_stall_reports_no_break`).
- Partner channel missing from the playlist, or equal to the channel being watched: fall back to Dim (Task 7 test `how`).

```python
# per sample (t, s):
if s >= PRESENT_FROM:
    present_from = t if present_from is None else present_from
    if t - present_from >= BACK_AFTER_S:
        if in_break: end it (breaks_seen += 1 if t - since >= COUNTS_AFTER_S)

if not in_break and absent_from is not None and s < GONE_BELOW and t - absent_from >= START_AFTER_S:

```

### Task 2: Learning a channel's logo and scoring frames

**Files:**
- Create: `iptv_curator/breaks/logo.py`
- Modify: `requirements.txt` (add `numpy`)
- Test: `tests/test_breaks_logo.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - Frames are `yuv420p` at **960×540** (`FRAME_W, FRAME_H = 960, 540`, `FRAME_BYTES = 960*540*3//2`); `def planes(raw: bytes) -> tuple[np.ndarray, np.ndarray, np.ndarray]` (Y 540×960, U and V 270×480, uint8).
  - Corners: `CORNERS = {"tl": (0, 0), "tr": (720, 0), "bl": (0, 405), "br": (720, 405)}`, box `BOX_W, BOX_H = 240, 135` (Y coordinates).
  - `def edges(raw: bytes, corner: str) -> np.ndarray` (bool, 135×240): `max(|ΔY|, 2·|ΔU|, 2·|ΔV|) > EDGE = 40` over horizontal and vertical neighbours, chroma upsampled ×2. Chroma is in on purpose: a yellow logo on snow differs in U, not in Y.
  - `class Learner`: `add(raw: bytes) -> None`; `done: bool`; `result() -> Logo | None`. Keeps only frames whose Y (downscaled ×8) differs from the last kept one by mean abs > `6`; done after `120` kept frames, or after `1200` frames seen (10 min at 2 fps).
  - `@dataclass class Logo: corner: str; mask: np.ndarray  # bool 135×240`; `to_json() -> dict` / `Logo.from_json(d) -> Logo` (mask as base64 of `np.packbits`); `score(raw: bytes) -> float` = share of mask pixels that are edges in this frame.
  - Mask rule: per corner, persistence = share of kept frames with an edge at the pixel; mask = persistence `>= 0.8`, ignoring a 2-px border; the corner chosen is the one with the most mask pixels within `[60, 0.2 × BOX_W × BOX_H]`; none qualifies → `result()` is `None`.

### Task 4: Watcher, store and the one-watcher manager

**Files:**
- Create: `iptv_curator/breaks/store.py`, `iptv_curator/breaks/watcher.py`
- Test: `tests/test_breaks_watcher.py`

**Interfaces:**
- Consumes: `Learner`, `Logo` (Task 2), `BreakRule` (Task 1).
- Produces:
  - `store.py`: `class BreakStore(dir: Path)` with `get(sid: int) -> dict | None`, `put(sid: int, rec: dict) -> None` (atomic, `storage.write_json`), `all() -> dict[int, dict]`, `thumb_path(sid) -> Path`. Record: `{"status": "learning"|"observing"|"works"|"unsupported", "logo": Logo.to_json() | None, "learned_at": iso, "breaks_seen": int, "failed_learns": int, "name": str}`. Files: `/data/breaks/<sid>.json`, thumbnail `/data/breaks/<sid>.png` (mean Y of the chosen corner while learning, saved with Pillow).
  - `watcher.py`:
    - `FrameSource = Callable[[str], Iterator[bytes]]` (url → frames of `FRAME_BYTES`; ends when the stream ends). `ffmpeg_source(mask_fn: Callable[[str], str]) -> FrameSource` makes the real one (in `app.py`: `ffmpeg_source(lambda s: mask(s, curator.settings))`): `ffmpeg -nostdin -hide_banner -loglevel error -user_agent "VLC/3.0.20 LibVLC/3.0.20" -threads 2 -i <url> -map 0:v:0 -an -sn -dn -vf fps=2,scale=960:540 -pix_fmt yuv420p -f rawvideo pipe:1`; stderr logged only through `mask_fn`; the process is killed when the iterator is closed.
    - `class Breaks(store: BreakStore, url_of: Callable[[int], str], names: Callable[[], dict[int, str]], source: FrameSource, clock=time.monotonic)` with `ask(sid: int) -> dict` (the reply below; renews the lease) and `stop() -> None`. Constants: `LEASE_S = 30`, `WARMUP_S = 5`, `RETRY_S = 60`, `MAX_FAILS = 3`, `STALL_S = 20`, `RELEARN_AFTER_S = 1200`, `MAX_LEARNS = 3`.
    - Reply: `{"status": <record status or "learning">, "break": bool, "id": int | None, "elapsed": int | None}`; `break` is true only while `status == "works"`, the rule is in a break and a frame arrived within `STALL_S`; `id` is the break's start as Unix seconds (stable for one break), `elapsed` whole seconds since.
    - Behaviour: one watcher thread at most. A new `sid` stops the current watcher at once. A watcher starts only after the same `sid` was asked for during `WARMUP_S`. It stops when no `ask` for `LEASE_S`. A start that yields no frame, or a stream that ends, counts as a failure; the next start waits `RETRY_S`; after `MAX_FAILS` the `sid` is left alone until a different `sid` is asked for. Learning: status `learning` feeds a `Learner`; result `None` → `failed_learns += 1`, `unsupported` at `MAX_LEARNS`; a logo → `observing`. `observing` → `works` when `BreakRule.breaks_seen >= 1`. In `works`, logo gone longer than `RELEARN_AFTER_S` → back to `learning` with the logo cleared.
